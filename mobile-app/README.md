# TW&D Engineering Mobile App

Native Android and iOS shell for TW&D Engineering Consult & Services Ltd.

App ID: com.twdengineeringconsult.app

## Build
From this directory:
1. npm install
2. npx cap add android
3. npx cap add ios
4. npx cap sync
5. npx cap open android / npx cap open ios

The app opens a lightweight mobile home screen and links to the live TW&D website.

## Store publication
Google Play requires a Play Console developer account and, for newer personal accounts, a closed test with at least 12 testers for 14 continuous days before production access. Apple App Store distribution requires Apple Developer Program membership.
